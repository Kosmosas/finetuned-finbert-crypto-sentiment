# Consolidated results

The tables and figures reported in the manuscript, in one place. Everything here
is regenerated by `make_results.py` from the artefacts the upstream notebooks
write; nothing is transcribed by hand.

```bash
python make_results.py          # run from this directory
```

## Where the inputs come from

| Stage | Notebooks | Writes to |
|---|---|---|
| Headline scoring | `sentiment_analysis/oof_finbert_scoring.ipynb`, `oof_score_full_stream.ipynb` | `sentiment_analysis/out/` |
| iTransformer | `itransformer_models/01`–`03` | `itransformer_models/out/` |
| LSTM | `lstm_models/01`–`03` | `lstm_models/out/` |

`make_results.py` recomputes only the Diebold–Mariano tests, so that both model
families are compared on one common set of timestamps. Everything else is read
as produced upstream.

| file | contents |

| `01_sentiment_leakage_before_after.csv` | single-checkpoint vs three out-of-fold variants: train/test correlation and sd break |

| `02_forecasting_itransformer.csv`, `02_forecasting_lstm.csv` | 3-seed mean ± sd per regime and feature set |
| `02_naive_benchmarks.csv` | zero-change, historical mean, random walk, AR(1), AR(24) |
| `03_diebold_mariano.csv` | both families, both baselines (zero-change and Price + volume), both regimes, BH-corrected |
| `04_backtest_metrics.csv` | every strategy × feature set × regime, with a `beats_bh` flag |
| `04_momentum_model_vs_no_model.csv` | model-driven momentum against the zero-forecast and shuffled-forecast controls |
| `04_cv_fold_stability.csv` | per-fold Sharpe at the selected configuration |
| `05_finbert_oof_folds.csv` | fold structure and per-fold calibration of the headline scoring model |
| `figures/` | epoch-selection and portfolio-trajectory figures, both families |
| `tex/` | LaTeX drop-ins for the tables above, plus the two methodology notes (`backtest_mechanics.tex`, `strategy_selection.tex`) |

Buy-and-hold references used throughout: **uptrend \$13,891**, **sideways
\$11,057**, on \$10,000 of initial capital.

## Caveat on the backtest numbers

The strategy parameter search is not reproducible run to run.
`02_*_backtesting.ipynb` calls `study.optimize(..., n_jobs=8)`, and Optuna's TPE
sampler is not deterministic under parallelism even with a fixed seed. Measured:
the pure-momentum benchmark — which involves no model at all and whose inputs did
not change — moved from 85 entries / \$11,153 to 201 entries / \$9,964 between two
consecutive runs. Backtest point estimates therefore carry search noise on top of
seed noise, and differences smaller than a few thousand dollars are not
interpretable. Set `n_jobs=1` for a reproducible, much slower search.
